# 3段構成での開発

名前・ID・URL はプロジェクトの `cf-envs.json` と CLAUDE.md にある。ここは型だけ。

## 出し方

| やりたいこと | すること | 報告に載せるもの |
|---|---|---|
| 作業途中をすぐ見せる | `npm run deploy:dev` | 開発の URL |
| 本番前の確認 | ブランチを push → `npm run deploy:url` | ステージングの URL |
| 本番に出す | main へ merge → `npm run deploy:url <merge のコミット>` | 本番の URL |

- **本番へは main への merge でしか出さない。** `wrangler deploy` を `--env dev` 無しで打たない
  (トークンが開発用 Worker にしか効かないので弾かれはする)
- `deploy:url` の終了コード 2 はビルド中。20 秒ほど置いて再実行する
- 作業環境から `*.workers.dev` には繋がらないことが多い。画面の確認は利用者に URL を渡す

## 速さと確かさの使い分け

- **見た目の調整(位置・大きさ・色・文言)を利用者と往復しているとき**は、手元のテスト・
  スクリーンショット・ステージングのビルド待ちを省く。直して `deploy:dev` し、開発の URL を
  返すだけ。テストは push で CI が回すので、落ちたらそこで直す
- **データ・API・計算に触るとき**は、手元でテストを回してから上げる
- **多くの画面のスクリプトに手を入れたとき**は、見た目の調整でも画面が真っ白にならないかだけ
  (構文チェックの入ったテスト)は見てから上げる
- **main へ merge する前**は必ず全部のテストを回す。main が先に進んでいたら取り込んで、
  衝突を解いてから回す

## D1

| | 開発用・ステージング用 | 本番 |
|---|---|---|
| 流し方 | MCP(`d1_database_query`) | MCP(`d1_database_query`) |
| 利用者の了解 | 要らない | **要る。** 対象の DB(名前と id)と SQL の全文を見せてから |
| 読むだけ | 自由 | 自由 |

トークンに D1 の権限は無いので、wrangler ではなく MCP で流す。

**スキーマを変える順番:** 開発用 → ステージング用(そのブランチを push する前。流し忘れると
プレビューが壊れる)→ 本番(merge の前後)。

**コードとマイグレーションは同時に出せない。** 列を足すなら、コードは列が無くても動く形にしておく
(作成は列が無ければ外して入れ直す、読み出しは `?? null` で受ける、落ちてよい更新は別の文に分ける)。

流したら `INSERT INTO d1_migrations (name) VALUES ('000N_xxx.sql')` で履歴も付け、
`sqlite_master` を読んで入ったことを報告に載せる。

## 設定を足すとき

`[env.dev]` と `[previews]` は本番の `vars` と `d1_databases`(ほかのバインディングも)を
引き継がない。**本番に変数・バインディングを足したら、この2か所にも足す。**
足し忘れると、開発やステージングでだけ `env.X` が undefined になる。

## ハマりどころ

- **`deploy:dev` の途中に出る認証エラーは失敗ではない。** 上げ終わったあと wrangler がアカウント
  全体の workers.dev サブドメイン(`/accounts/<id>/workers/subdomain`)を読みに行き、トークンが
  その Worker にしか効かないので断られる。スクリプトは `wrangler deployments list` で今回の
  デプロイかを見て成否を決めている
- **Worker Previews はチェックの本文に URL を書かない。** `deploy:url` はビルドのリンク
  (`/previews/<名前>/builds/…`)からステージングの URL を組み立てる
- **`wrangler deploy --dry-run`(env 無し)は「複数の環境があるのに指定が無い」と警告する。**
  本番のビルドはそれで正しいので気にしない
- **Worker Previews への切り替えは元に戻せない。** 切り替え前のプレビュー(バージョンの URL)は
  本番の D1 を読んでいたので、古い URL で試さない
